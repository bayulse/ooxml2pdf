# Local reference assets

No Microsoft Office-generated reference assets are distributed here.

Use ignored `local/<case-stem>/` for local references to public decks, and ignored
`private/<case-stem>/` for proprietary inputs. A case directory contains ordered
PNG files plus `reference.json`. The `reference` command creates the manifest;
see [the workflow](../../docs/COMPATIBILITY.md).

Renderer identity must be explicit. LibreOffice references describe LibreOffice's
output and must not be relabeled as PowerPoint.
