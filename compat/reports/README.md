# Corpus reports

Batch mode writes `summary.json`, `summary.md`, `fidelity-gaps.json` and
`fidelity-gaps.md` into ignored `public/` or `private/` directories. Single-case
reports live beside their artifacts in `compat/outputs/`.

Private reports contain sensitive filenames and warning locations. Keep them in
ignored paths; review provenance and redistribution permission before publishing
any reference material or report excerpts.
