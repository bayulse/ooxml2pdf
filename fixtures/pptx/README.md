# Synthetic package fixtures

All documents here are generated specifically for this repository's tests.
They contain no organizational documents, proprietary assets or personal data.
ZIP timestamps are fixed. The one-pixel PNG is generated from original RGBA
bytes by Rust. These are tiny package/parser fixtures, not Office fidelity
reference documents.

| File | Purpose |
| --- | --- |
| `minimal.pptx` | One empty slide, complete OPC metadata and relationships |
| `one-image.pptx` | One slide, one PNG, relative image target, external hyperlink |
| `three-slides.pptx` | Three slide parts with relationships |
| `malformed-relationships.pptx` | Relationship missing required `Type` |
| `malformed-xml.pptx` | Truncated relationship XML |
| `path-traversal.pptx` | ZIP member named `../escape.dat` |
| `target-traversal.pptx` | Package relationship tries to escape the root |
| `entry-limit.pptx` | 21 entries; fails at a configured maximum of 20 |
| `compression-abuse.pptx` | 1 MiB of zeros exceeds the default compression ratio |

Regenerate deterministically with:

```sh
cargo run --offline -p o2p-ooxml --example generate_fixtures
```

Additional damaged ZIPs, limits and XML cases are constructed in Rust tests to
exercise exact corruption and resource boundaries. No Office content is rendered.

## Milestone 1B presentation fixtures

These additional fixtures exercise presentation metadata and intentionally blank
PDF conversion. Existing Milestone 1A fixture bytes are unchanged.

| File | Purpose |
| --- | --- |
| `one-slide-standard.pptx` | One slide, 4:3, 9,144,000 × 6,858,000 EMUs (720 × 540 points) |
| `three-slides-standard.pptx` | Three slides at the same standard size |
| `three-slides-16x9.pptx` | Three slides, 12,192,000 × 6,858,000 EMUs (960 × 540 points) |
| `reordered-slides.pptx` | Presentation order is slide3, slide1, slide2; IDs are 900, 300, 600 and `.rels` order is different again |
| `missing-slide-size.pptx` | Valid OPC package with no `sldSz`; conversion must fail |
| `malformed-slide-size.pptx` | Valid OPC package with zero slide width; conversion must fail |
| `deep-presentation.pptx` | 65 levels of XML nesting; rejected before recursive tree construction |

Regenerate these fixtures deterministically with:

```sh
cargo run --offline -p o2p-pptx --example generate_fixtures
```

The normalized ordered slide references prove ordering; blank pages of equal
size have no visual slide identity. Tests also check empty PDF content streams,
page counts and MediaBoxes with an independent PDF reader. Presentation-size
errors and nesting errors remain inspectable through the metadata-only package
inventory command, which deliberately does not parse presentation semantics.

## Milestone 1F text fixtures

Regenerate with `cargo run --offline -p o2p-pptx --example generate_fixtures`.
All text and image content is synthetic and non-proprietary.

| Fixture | Purpose |
| --- | --- |
| `one-text-box.pptx` | Positioned single text box containing Hello |
| `unicode-text.pptx` | Ordered Hello, Indonesia, Résumé, 日本語 paragraphs |
| `multiple-runs.pptx` | Ordered adjacent runs with differing sizes/styles |
| `multiple-paragraphs.pptx` | Paragraph breaks and a blank paragraph with end style |
| `styled-text-basic.pptx` | Direct size, bold, italic, red sRGB and explicit break |
| `text-in-rectangle.pptx` | Text together with rectangle fill and outline |
| `text-with-image.pptx` | Readable text, vector paint and original raster quadrants |
| `overlapping-text-shape.pptx` | Text both underneath and above a rectangle |

The current fixed Helvetica fallback renders Western Unicode including Résumé.
Japanese glyphs are deliberately rendered as `???` by the CLI with structured
warnings. Literal Unicode remains in the normalized model; strict PDF `render`
returns UnsupportedText for glyphs outside WinAnsi. Neither rendering path uses
system fonts, theme/master/layout resolution, wrapping, autofit or shaping.


`unicode-fonts.pptx` is a deterministic Milestone 1G-A regression fixture with
explicit `O2P Test Sans` / `O2P Test Arabic` typefaces: ASCII, Résumé, ffi,
combining marks, Greek/Cyrillic, 日本語 and Arabic. It contains no embedded fonts;
register the licensed [font fixtures](../fonts/README.md) for Unicode rendering.
The existing generator reproduces it alongside all earlier fixtures.

## Milestone 1H transform fixtures

Regenerate with the existing `o2p-pptx` example. These nine original, minimal
fixtures use direct off/ext, synthetic vector geometry, a four-color 2x2 PNG,
and explicit text. No groups, inherited transforms or external assets occur.

| Fixture | Purpose |
| --- | --- |
| rotated-rectangle-45.pptx | 45-degree fill and outline about a nonzero center |
| rotated-rectangle-90.pptx | Exact quarter turn; preserve pre-rotation bounds |
| rotated-ellipse.pptx | Native rotated ellipse fill and outline |
| rotated-image.pptx | Quarter-turn quadrant PNG as an image XObject |
| rotated-text.pptx | Shared rectangle/text rotation; Résumé/日本語/ffi wrapping |
| flipped-horizontal.pptx | ABC labels reveal horizontal reflection |
| flipped-vertical.pptx | ABC labels reveal vertical reflection |
| flipped-and-rotated.pptx | Both flips composed with 45-degree rotation |
| mixed-transforms.pptx | Nine elements: rotated shapes/text, shared PNG, flips and line |

```sh
cargo run --offline -p o2p-cli -- convert fixtures/pptx/mixed-transforms.pptx -o target/mixed-transforms.pdf
```

Add `--font-dir fixtures/fonts` to exercise embedded Unicode fonts and wrapping.
Legacy font-resolution and unwrapped overflow warnings remain expected for text
boxes. The transform fixtures contain no unsupported element transforms.
